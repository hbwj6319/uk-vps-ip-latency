### IP类型：机房IP、双ISP和家宽是三回事

普通VPS给的是机房IP，在IP归属库里显示为hosting，用来建站、跑服务没问题，但拿去做英区电商或社媒账号，很容易被平台判定为机房流量。双ISP和家宽住宅IP在IP库里登记的是运营商属性，这也是这两年英国VPS各家纷纷上双ISP产品线的原因——亚马逊英国站、TikTok英区这类业务对IP属性的检查越来越严。

家宽和双ISP通常比同配置的机房IP贵不少。买之前先想清楚自己的业务吃不吃IP属性，不吃就别多花这笔钱。

### 三网延迟：同一台服务器，不同运营商能差出三倍

Kamatera伦敦节点的测评数据是个典型例子：电信平均255ms、联通254ms，移动却高达607ms。同一台服务器，移动用户等待的时间几乎是电信用户的两倍半。Evoxt同样在伦敦，移动走CMI线路，实测240–325ms，就正常得多。

所以看测评别只看“平均延迟”，先找到自己运营商那一行的数字。

Evoxt标称G口带宽，Speedtest实测上下行850/874 Mbit/s，标称和实测基本一致；Kamatera标称10Gbps，同价位里带宽给得算足的。反过来，HostMedia年付7.5英镑那档只有100Mbps——不限流量的套餐带宽一般都不高，这是行业里常见的取舍。
